Análisis de Ventas de VentaExpress

Limpieza, transformación y visualización de datos con Excel y Google Sheets

Descripción del proyecto

Este proyecto fue desarrollado como parte de mi formación en el Bootcamp de Data Analyst.

El objetivo fue analizar los datos comerciales de **VentaExpress**, una empresa ficticia dedicada a la venta de productos tecnológicos, para transformar información sin procesar en indicadores que apoyen la toma de decisiones.

El trabajo comprende la limpieza, transformación, análisis y visualización de datos, así como la elaboración de un informe ejecutivo con los principales hallazgos.

Objetivos

- Identificar y corregir problemas de calidad de datos.
- Estandarizar la información para facilitar su análisis.
- Calcular indicadores comerciales.
- Analizar el comportamiento de las ventas por producto y ciudad.
- Presentar los resultados mediante visualizaciones y un informe ejecutivo.

Herramientas utilizadas

- Microsoft Excel: análisis y organización de datos.
- Google Sheets: limpieza, transformación y aplicación de fórmulas.
- Tablas y gráficos: visualización de indicadores comerciales.

Limpieza y transformación de datos

Se trabajó con 753 registros de ventas.

Durante el proceso se realizaron las siguientes actividades:

1. Identificación de valores faltantes.
2. Recuperación de 10 precios unitarios y 6 montos totales mediante cálculos.
3. Separación de la información de productos en categoría, tipo y especificaciones.
4. Estandarización de nombres de ciudades.
5. Validación de los montos de venta.
6. Verificación de identificadores de órdenes para identificar posibles duplicados.

Indicadores y resultados

| Indicador | Resultado |

| Registros analizados | 753 |
| Ventas totales | $2.944.620,61 |
| Ciudad con mayores ventas | Monterrey |
| Producto más vendido | Laptop-Oficina-32GB |

Los resultados permitieron identificar patrones comerciales y oportunidades de mejora en la gestión de ventas.

Principales aprendizajes

Este proyecto me permitió fortalecer mis habilidades en:

- Limpieza y preparación de datos.
- Uso de fórmulas en hojas de cálculo.
- Transformación y normalización de información.
- Análisis de indicadores comerciales.
- Interpretación de resultados.
- Comunicación de hallazgos mediante un informe ejecutivo.
